# TitleLab · 爆款标题实验室

发布前的 1 秒判官 —— 一个跑在浏览器里的小红书标题「爆款概率」预测器。输入候选标题，本地模型 1 秒内给分、6 维诊断、一键生成优化版本，标题 100% 在本机处理，零上传、零注册、零埋点。

> 纯前端开源 · 数据不出浏览器 · 基于真实爆款案例数据集训练 · 支持导入你的真实数据重训

## 核心功能

- **爆款概率评分**：双模型（逻辑回归 + 神经网络）融合，输出 0-100 分 + 等级 + 双子分（打开吸引力/搜索友好度）+ 同赛道分位
- **6+1 维诊断**：情绪浓度 / 具体度·数字感 / 长度适配 / 热词命中 / 悬念好奇 / 平台语感 / 广告营销感，命中词高亮圈注 + 人话解释
- **广告营销感检测 + 标题党风险**：识别「巨显白／必买／闭眼入」等硬广话术与「改变命运／逆袭」等过度承诺，判定「疑似广告投流/软文」，提示新号会被当广告划走
- **发布建议**：基于真实爆款拆解归纳的封面（数字前置放大/结果前置）、构图（人物出镜/主体突出）、文风（口语化+黄金三段式）、发布时间建议
- **一键优化改写**：5 种爆款策略（数字盘点/悬念反差/身份代入/情绪共鸣/避雷警示），生成后自动重新打分
- **A/B 对比**：原题 vs 变体双栏六维对比，自动判胜负
- **历史记录**：localStorage 保存 50 条，点击回填重测
- **模型透明度**：训练指标（Acc/AUC/F1）+ 特征权重 + 训练损失曲线 + 数据集来源声明
- **真实数据导入重训**：导入你抓取的「标题,点赞,收藏,评论」CSV，模型在本机用真实互动数据重新训练（≥40 条，中位数分档，数据不出浏览器）

## 技术亮点（机器学习落地方式）

- **浏览器内实时训练**：加载时用内置数据集训练，逻辑回归（全批梯度下降 + L2）+ 双隐层神经网络（He 初始化 + Adam + 早停），全程无后端、无 API Key
- **特征工程**：字符级 1/2-gram TF-IDF（sublinear TF + 平滑 IDF + L2 归一）+ 14 项数值特征（z-score）
- **可解释**：逻辑回归权重直接可视化「什么在拉高/拉低你的分」
- **防泄漏**：词表与统计量仅在训练集构建；分层切分 60/20/20，种子固定可复现
- **诚实标注**：数据集三层构成——①真实爆款案例（公开爆文拆解文章收录，含点赞 2.6w~30w 案例）②按已发表 9 大爆款公式构造样本 ③避坑教程收录的真实反面教材；并注入约 8% 标签噪声模拟真实互动不确定性。不含平台原始互动明细，需要真数据请用「导入重训」
